# alias: data preparation

Personalities generation → consensus selection → Wikipedia articles retrieval → validation. The original full ensemble pipeline is not included. `prompts/` contains the two supplied Russian & English generation templates, not runtime prompts; the retained game inputs are under `multiturn_games_benchmark/datasets/alias/`.

Paths are relative to the repository root unless local to this module. See the [command guide](../../docs/repository.md#auxiliary-commands) for runnable examples.
