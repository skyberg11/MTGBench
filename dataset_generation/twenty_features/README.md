# twenty_features: data preparation

Word generation → consensus selection → generation and filtering of feature values → seeded sampling of descriptions → validation. The original full ensemble pipeline is not included. `prompts/` contains the two supplied Russian generation templates, not runtime prompts; the retained game inputs are under `multiturn_games_benchmark/datasets/twenty_features/`.

Paths are relative to the repository root unless local to this module. See the [command guide](../../docs/repository.md#auxiliary-commands) for runnable examples.
