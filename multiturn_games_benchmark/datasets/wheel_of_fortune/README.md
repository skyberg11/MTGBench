# wheel_of_fortune

`en_letter_difficulty_words.json` and `ru_letter_difficulty_words.json`: metadata plus a `words` array with `word`, `difficulty_score`, `level` and `length`. Five stored strata A2–C2 control sampling. Three Easy/Medium/Hard analysis buckets are a separate grouping. The Russian source frequency CSV is under `dataset_generation/wheel_of_fortune/resources/`.

Paths mentioned above are relative to the repository root. See [data sources and terms](../../../THIRD_PARTY_NOTICES.md).
