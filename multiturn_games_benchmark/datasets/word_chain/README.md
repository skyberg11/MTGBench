# Word Chain locality data

The JSONL files in this directory are adapted from the Geoapify world cities
database, which is compiled from OpenStreetMap data and distributed under the
[Open Database License 1.0][odbl].

MTGBench normalizes locality names, separates English and Russian forms,
includes available alternative names, and creates filtered gameplay and
validation subsets. The files are therefore distributed as an adapted database
under ODbL, not under the repository's CC BY 4.0 data license.
