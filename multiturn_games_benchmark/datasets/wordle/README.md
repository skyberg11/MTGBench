# wordle

`wordle_en.jsonl` and `wordle_ru.jsonl`: one JSON object per line with `word` (a five-letter noun) and `bucket` (`1`, `2`, `3`: Easy, Medium, Hard). Noun validation uses WordNet / RuWordNet. Historical baseline turn counts are in `results/baselines/wordle/`.

Paths mentioned above are relative to the repository root. See [data sources and terms](../../../THIRD_PARTY_NOTICES.md).
