# twenty_features

`words_descrs_shuffled_new_en` and `words_descrs_shuffled_new_ru` are Python pickle mappings from words to ordered feature descriptions. Pass this directory to `--table-path`. The two Russian generation prompts have moved to `dataset_generation/twenty_features/prompts/`.

Paths mentioned above are relative to the repository root. See [data sources and terms](../../../THIRD_PARTY_NOTICES.md).
