# twenty_questions_consistency

`synthetic_en_400_episodes.jsonl` and `synthetic_ru_400_episodes.jsonl`: synthetic episode objects. The controller contains `words_to_hypernyms`, mapping generated words to hierarchical attributes. The runner selects the secret word and supplies the pool to the model.

Paths mentioned above are relative to the repository root. See [data sources and terms](../../../THIRD_PARTY_NOTICES.md).
